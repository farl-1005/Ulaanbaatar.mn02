# Backend (`server/`)

Admin-ы засвар болон иргэдийн илгээсэн маягтууд SQLite өгөгдлийн санд (`data/ub.sqlite`) хадгалагдана.

```bash
npm run dev     # хөгжүүлэлт: http://localhost:8080 (сайт + backend, файл хадгалахад дахин бүтээнэ)
npm run build && npm start   # production: http://localhost:3000 (PORT-оор солино)
```

## Admin нэвтрэх
- Сайтын хөлийн **"Удирдлага"** холбоос эсвэл `/#admin` хаяг.
- Нууц үг нь `.env` файлын `ADMIN_PASSWORD`. Анх асаахад `.env` байхгүй бол санамсаргүй нууц үг үүсгэнэ. Солих бол `.env`-г засаад серверийг дахин асаана. Тохиргооны жишээ: `.env.example`.

## Admin-аас засагдах хэсгүүд
| Бүлэг | Хэсгүүд |
|---|---|
| Агуулга | Мэдээ, Анхааруулга, Арга хэмжээ, Медиа (бодит бичлэгийн холбоостой), Төслүүд, Үйлчилгээ, Амьдралын нөхцөл (алхмуудтай), Ил тод байдал (тогтоол, захирамж, тендер, PDF холбоос) |
| Хотын тухай | Удирдлагын бүтэц, Харьяа байгууллага (вэб холбоостой), Түүх, Хотын статистик (хүн ам, төсөв, түгжрэл) |
| Бүтэц, ангилал | Үндсэн цэс (дотоод хэсэг эсвэл гадаад холбоос), Мэдээ / арга хэмжээ / төслийн ангилал (нэр, өнгө), Санал хүсэлтийн сэдэв, AI туслахын хариултууд |
| Систем | Гарчиг, текст (сайтын бүх бичвэр), Тохиргоо (гол мэдээ, Засаг даргын мэдээ, түгээмэл үйлчилгээ, санал болгох асуулт, хайлтын үгс) |

Засваргүй бол `src/data.js`, `src/data2.js`-ийн анхны агуулга харагдана. Admin дээрх «Анхны хувилбарт буцаах» нь засварыг устгаж анхных руу нь буцаана.

## Юу хийдэг вэ
- **Шууд шинэчлэлт:** admin хадгалах бүрд нээлттэй бүх хөтөч `/api/events`-ээр мэдэгдэл авч, дахин ачаалахгүйгээр шинэчлэгдэнэ.
- **Маягтууд:** "Эрсдэл мэдээлэх" (зурагтай), "Санал хүсэлт", имэйл бүртгэл нь admin-ы **Ирсэн хүсэлт** хэсэгт харагдаж, төлөвийг нь (Шинэ / Шийдвэрлэж буй / Шийдвэрлэсэн / Татгалзсан) сольж болно. Иргэний зураг `data/uploads/`-д хадгалагдаж, зөвхөн админд харагдана.
- **Сервергүй үед:** `dist/ulaanbaatar-mn.html` (нэг файлт хувилбар) шиг backend-гүй ажиллавал өмнөх шигээ хөтчийн санах ойд хадгална.

## Мэдээ бүр өөрийн хаягтай (`server/pages.js`)
- Мэдээ `/news/<id>` хаягтай. Сервер HTML-д нь гарчиг, тайлбар, `og:` / `twitter:` tag, JSON-LD (NewsArticle), мэдээний текстийг шууд оруулдаг тул Facebook, Google зэрэг JS ажиллуулдаггүй робот ч зөв харна. Хөтөч дээр app.js ачаалагдаад ердийнхөөрөө ажиллана.
- Admin-аас нэмсэн, засварласан мэдээ шууд тусгагдана (build хүлээхгүй).
- Share хийхэд харагдах 1200×630 зураг: `/og/<id>.jpg` (бодит зураг, admin-аас оруулсан зураг эсвэл чимэглэлээс sharp-аар үүсгэж `dist/.og/`-д кэшлэнэ).
- `/sitemap.xml`, `/robots.txt` автоматаар үүснэ. Хайлтын системд бүртгүүлэхдээ sitemap-ын хаягийг Google Search Console-д өгнө.
- Хаягийн домэйн: `.env`-ийн `SITE_URL` → `DOMAIN` → хүсэлтийн Host.
- Хуучин `/#news/<id>` холбоос `/news/<id>` руу шилжинэ. Сервергүй (нэг файлт, статик) хувилбар `#news/<id>`-ээр ажилласаар байна.
- Facebook хуучин preview-г кэшлэдэг. Шинэчлэх бол https://developers.facebook.com/tools/debug дээр хаягаа оруулж "Scrape Again" дарна.

## Хамгаалалт
- Засах бүх үйлдэл нэвтрэлт шаардана (HttpOnly cookie, 7 хоног; өгөгдлийн санд зөвхөн token-ы hash хадгална).
- Өөр сайтаас ирсэн бичих хүсэлтийг (Origin шалгалт) хаана.
- Нэвтрэх оролдлого: 15 минутад 10. Маягт: нэг IP-ээс цагт 30.
- Reverse proxy (nginx г.м.) ард ажиллуулбал `.env`-д `TRUST_PROXY=1` гэж тохируулна (HTTPS дээр cookie `Secure` болно).

## Нөөцлөх
`data/` хавтсыг (ub.sqlite, uploads) тогтмол хуулж хадгална. Энэ хавтас git-д орохгүй.

## API
| Хүсэлт | Эрх | Үүрэг |
|---|---|---|
| `GET /api/cms` | бүгд | Admin-ы засварууд (overlay) |
| `PUT` / `DELETE /api/cms/:col/:id` | admin | Засвар хадгалах / буцаах |
| `POST /api/cms-log` | admin | Өөрчлөлтийн түүх |
| `POST /api/login`, `/api/logout` | бүгд | Нэвтрэх / гарах |
| `POST /api/submit/report\|idea\|digest` | бүгд | Маягт илгээх |
| `GET /api/submissions` | admin | Ирсэн хүсэлтүүд |
| `PATCH` / `DELETE /api/submissions/:id` | admin | Төлөв солих / устгах |
| `GET /api/events` | бүгд | Шууд мэдэгдэл (SSE) |
| `GET /uploads/:file` | admin | Иргэний оруулсан зураг |
| `GET /news/:id` | бүгд | Мэдээний хуудас (og: tag, JSON-LD) |
| `GET /og/:id.jpg` | бүгд | Share хийхэд харагдах зураг (1200×630) |
| `GET /sitemap.xml`, `/robots.txt` | бүгд | Хайлтын системд |
