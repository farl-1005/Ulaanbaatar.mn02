# ulaanbaatar.mn: эх код

## Суулгах программ
- **Node.js LTS** (20 ба түүнээс дээш хувилбар): https://nodejs.org. npm хамт суулгагдана.
- **Visual Studio Code**: https://code.visualstudio.com. Санал болгох өргөтгөл: *Tailwind CSS IntelliSense*, *Prettier*.

## Эхлүүлэх
```bash
npm install     # нэг удаа: Tailwind CSS, Lucide икон, nodemon татна
npm run dev     # nodemon: бүтээгээд http://localhost:8080 дээр ажиллуулна
npm run build   # зөвхөн бүтээх (байршуулахын өмнө)
```
`npm run dev` ажиллаж байхад `src/` доторх файлыг хадгалах бүрд nodemon автоматаар дахин бүтээж, нээлттэй хөтөч өөрөө refresh хийгдэнэ. Бүтээх үед алдаа гарвал хуудасны доод талд улаан мэдэгдлээр харагдана, засаад хадгалахад алга болно. Гараар дахин бүтээх бол терминалд `rs` гэж бичээд Enter дарна.

Бүтээсний дараа `dist/site/` хавтас нь байршуулахад бэлэн вэб сайт, `dist/ulaanbaatar-mn.html` нь бүх зүйлийг нэг файлд багтаасан хувилбар байна.

## Файлын бүтэц (src/)
| Файл | Агуулга |
|---|---|
| `template.html` | HTML араг бүтэц, фонт, мета |
| `input.css` | Өнгөний токен (гэрэлтэй/харанхуй), хөдөлгөөн, бүрэлдэхүүнүүдийн загвар |
| `data.js` | Сайтын бүх текст (МН/EN), анхааруулга, мэдээ, медиа |
| `data2.js` | Үйлчилгээ, амьдралын нөхцөл, төсөл, арга хэмжээ, тогтоол, тендер, Миний булан, чатын хариулт |
| `scene.js` | Кодоор зурдаг чимэглэл, лого, хотын схем газрын зураг |
| `core.js` | Туслах функц, header, цэс, гүйдэг мөр, хайлт, чиглүүлэлт |
| `sections.js` | Нүүр хуудасны хэсгүүд, газрын зургийн бөөгнөрөл |
| `skyline.js` | Header-ийн хөдөлгөөнт хотын зураг |
| `cms.js` | Admin-ы өгөгдлийн давхарга (анхны агуулга + засвар) |
| `admin.js` | Удирдлагын хэсгийн дэлгэц, засварлагч |
| `features.js` | Цонхнууд (нэвтрэх, мэдээлэх, санал), чат, эхлүүлэх код |

## Анхаарах зүйл
- **Tailwind:** Ангиллуудыг (жишээ нь `bg-ubred`, `lg:grid-cols-3`) JS доторх текстээс автоматаар уншина. Ангиллын нэрийг бүтнээр нь бичнэ (`'bg-' + color` гэж залгаж болохгүй).
- **Икон:** `ic('нэр')` гэж бичнэ. Нэрийг https://lucide.dev/icons -оос авна. Байхгүй нэр бичвэл бүтээх үед мэдэгдэнэ.
- **Өнгө:** `src/input.css`-ийн эхэнд байрлах `--c-red`, `--c-navy` зэрэг токеноор солино.
- **Admin:** Локал дээр өөрчлөлт хөтчийн санах ойд хадгалагдана. Олон хүн хамтран засахын тулд `src/cms.js`-ийн `cmsWrite`, `cmsDelete`, `initCMS` функцуудыг өөрийн сервер эсвэл API руу холбоно.
- **Бодит мэдээ:** ulaanbaatar.mn-ийн API: `https://ulaanbaatar.mn:8443/api/article?pageSize=20&type=TIME_HISTORY`
