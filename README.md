# ulaanbaatar.mn: эх код

## Суулгах программ
- **Node.js LTS** (20 ба түүнээс дээш хувилбар): https://nodejs.org. npm хамт суулгагдана.
- **Visual Studio Code**: https://code.visualstudio.com. Санал болгох өргөтгөл: *Tailwind CSS IntelliSense*, *Prettier*.

## Эхлүүлэх
```bash
npm install     # нэг удаа: Tailwind CSS, Lucide икон, nodemon татна
npm run dev     # nodemon: бүтээгээд http://localhost:8080 дээр ажиллуулна
npm run build   # зөвхөн бүтээх (байршуулахын өмнө)
npm run news    # ulaanbaatar.mn-ээс мэдээг одоо шууд дахин татах
```
`npm run dev` ажиллаж байхад `src/` доторх файлыг хадгалах бүрд nodemon автоматаар дахин бүтээж, нээлттэй хөтөч өөрөө refresh хийгдэнэ. Бүтээх үед алдаа гарвал хуудасны доод талд улаан мэдэгдлээр харагдана, засаад хадгалахад алга болно. Гараар дахин бүтээх бол терминалд `rs` гэж бичээд Enter дарна.

Бүтээсний дараа `dist/site/` хавтас нь байршуулахад бэлэн вэб сайт, `dist/ulaanbaatar-mn.html` нь бүх зүйлийг нэг файлд багтаасан хувилбар байна.

## Файлын бүтэц
Дэлгэрэнгүй: [ARCHITECTURE.md](ARCHITECTURE.md).

| Хавтас | Агуулга |
|---|---|
| `src/data/` | Анхны агуулга: текст (МН/EN), мэдээ, медиа, үйлчилгээ, төсөл, арга хэмжээ г.м. |
| `src/core/` | Туслах функц, төлөв, header, цэс, гүйдэг мөр, хайлт, чиглүүлэлт |

| `src/features/` | Цонхнууд (мэдээ унших, нэвтрэх, мэдээлэх, санал), чат, цаг агаар, эхлүүлэх код |
| `src/admin/` | Admin-ы өгөгдлийн давхарга (`cms.js`), удирдлагын дэлгэц (`admin.js`) |

| `server/sources/` | Build үед ulaanbaatar.mn, ipiu.mn-ээс татах өгөгдөл |
| `deploy/` | Сервер дээр байршуулах скриптүүд |

## Анхаарах зүйл
- **Tailwind:** Ангиллуудыг (жишээ нь `bg-ubred`, `lg:grid-cols-3`) JS доторх текстээс автоматаар уншина. Ангиллын нэрийг бүтнээр нь бичнэ (`'bg-' + color` гэж залгаж болохгүй).
- **Икон:** `ic('нэр')` гэж бичнэ. Нэрийг https://lucide.dev/icons -оос авна. Байхгүй нэр бичвэл бүтээх үед мэдэгдэнэ.
- **Өнгө:** `src/styles/01-base.css`-ийн эхэнд байрлах `--c-red`, `--c-navy` зэрэг токеноор солино.
- **Admin:** Локал дээр өөрчлөлт хөтчийн санах ойд хадгалагдана. Олон хүн хамтран засахын тулд `src/admin/cms.js`-ийн `cmsWrite`, `cmsDelete`, `initCMS` функцуудыг өөрийн сервер эсвэл API руу холбоно.
- **Бодит мэдээ (`server/sources/news.js`):** build бүрт ulaanbaatar.mn-ийн API-аас (`https://ulaanbaatar.mn/api/article?type=TIME_HISTORY`) сүүлийн 30 мэдээг бүтэн текст, үзэлттэй нь татна. API нь хөтчөөс шууд хандахыг (CORS) хаадаг тул Node.js талд татдаг.
  - Кэш: `dist/.news/`. 15 минутаас шинэ бол дахин татахгүй; сүлжээ тасарвал хуучин кэш, кэш ч байхгүй бол `src/data/news.js`-ийн жишээ мэдээг ашиглана.
  - Зураг: нүүр зургийг (дунджаар 2.5MB) `sharp`-аар 960px WebP болгож `dist/site/assets/news/`-д хийнэ (дунджаар ~60KB). 25MB-аас том зургийг алгасаж чимэглэлээр орлуулна.
  - Рубрик: API-д ангилал байхгүй тул `server/sources/news.js`-ийн `RUBRICS` түлхүүр үгээр тааварлана.
  - `src/data/news.js`-д ижил ID-тай мэдээ байвал түүний англи орчуулга, рубрик, үйлдлийн товчийг хадгалж, текст/огноо/үзэлт/зургийг бодитоор сольно. Бусад бодит мэдээ англи хувилбартаа монголоор харагдана.
  - Сайтыг байршуулсны дараа мэдээ шинэчлэгдэхийн тулд `npm run build`-ийг тогтмол (жишээ нь 15 минут тутам) дахин ажиллуулах хэрэгтэй.
